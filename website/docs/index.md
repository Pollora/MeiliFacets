# MeiliFacets

Faceted search for [Pollora](https://github.com/Pollora) projects, powered by
[Meilisearch](https://www.meilisearch.com). The server renders the first page with the filters in
the URL already applied; every filter, sort and page change after that is a single request from the
browser to Meilisearch, with no WordPress in the loop.

:::info[Work in progress]

This site is being written. Until it covers installation and configuration, the
[README](https://github.com/Pollora/MeiliFacets#readme) is the reference.

:::
